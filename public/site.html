Behind the Numbers

Research Methodology

Our institutional research process is documented, reproducible, and auditable. Here's exactly how we do it.

A

Source Identification

Curated 611 data sources spanning government APIs (FRED, Census, BLS, FDIC, FEMA, SEC EDGAR, EPA, EIA, Treasury), municipal portals (NYC PLUTO, Chicago Open Data, Dallas), RSS feeds (Bloomberg, Federal Reserve, CFPB, Commercial Observer), and live API integrations (Finnhub for REITs, CoinGecko for crypto, Walk Score for location).

B

Classification & Tagging

Each source is tagged with metadata: connector type (REST/RSS/Socrata/ArcGIS/Bulk), auth requirement (none vs free API key vs paid), update frequency, data category (14 categories), and reliability score. 400 sources require zero auth; 211 use free API keys.

C

Async Parallel Scraping

Python asyncio with httpx for concurrent fetches. Tenacity for retry logic with exponential backoff. Custom connectors per source type. 549 of 611 sources successfully scraped (91% success rate). 8,223 individual records collected across all categories.

D

Live API Enrichment

13 real-time API keys layered on top of scraped data: FRED (20 economic series), BLS (CPI, employment), Census (Pensacola MSA demographics), BEA (GDP), Finnhub (10 REIT prices), CoinGecko (BTC/ETH), Walk Score (location walkability), OpenWeather (current conditions), EIA (energy prices), Twelve Data, Alpha Vantage, NY Fed, Treasury.gov.

E

Source Attribution

Every data point on the terminal displays its source. Investors can click any number to see the original API call, response timestamp, and data lineage. No black-box analytics. Reports include full citation trails for due diligence.
